The post-scan menu opens with the three ways to keep nestjs-doctor running: `Review every pull request` (the GitHub Action), `Check every commit` (appends a `--staged --blocking error` scan pinned to the running version to `.husky/pre-commit`, or shows a snippet for lefthook and simple-git-hooks) and `Rescan after every agent edit` (the agent skill). The one the repository is closest to sits first with a `Recommended` badge; markdown and share move behind `More`. A hook install reports `command_completed` with `command: hook_install`.
