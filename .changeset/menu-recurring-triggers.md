The post-scan menu names what each recurring trigger does for you: `Review every pull request` (the GitHub Action), `Check every commit` (a `--staged --blocking error` scan of the scanned directory, pinned to the running version, appended to `.husky/pre-commit`, or a snippet for lefthook and simple-git-hooks) and `Rescan after every agent edit` (the agent skill). The item the repository is closest to sits first with a `Recommended` badge and a color sweep. A finished hook install reports `command_completed` with `command: hook_install`.
