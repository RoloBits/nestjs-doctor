# Quickstart

Run this at your project root.

```bash
npx nestjs-doctor@latest .
```

No install, no config file, no network calls. It reads your TypeScript, runs 50
rules, and prints a score out of 100.

![CLI output](/cli-output.png)

## Reading the output

The score is weighted by severity and category, then normalised by project size,
so a small project with three errors scores worse than a large one with three.
It always covers the whole project, whatever you scope the report to.

Findings are grouped by rule, worst first. Add `--verbose` for the file and line
behind each one.

```bash
npx nestjs-doctor@latest . --verbose
```

## Installing it

`npx` is enough for a one-off. Install it when you want the same version pinned
for everyone, or the VS Code extension, which loads it from your workspace.

```bash
npm install -D nestjs-doctor
```

## Exit codes

| Code | Meaning |
|------|---------|
| `0` | Passed |
| `1` | A gate failed: errors were found, or the score is below `--min-score` |
| `2` | Bad input: the path does not exist, or a flag is invalid |

The console report exits `1` on any error-severity finding. `--json` and
`--score` exit `0` unless you set a gate, because those exit codes predate the
`--blocking` flag. Pass `--blocking error` to make every mode agree.
